# 核心提示词与提示工程说明

> 对应代码：`app/prompts.py`　接口：`/api/outline`、`/api/essay`、`/api/review`

## 一、为什么不是“一句话让 AI 写作文”

直接把“写一篇高考满分作文”丢给模型，常见问题是：立意漂移、结构松散、素材堆砌、语言空泛、字数失控。  
本项目把“阅卷老师的评分经验”拆成模型可以执行的步骤，核心做法是：

1. **先审题立纲，再依纲成文**：把“想”和“写”分开，降低跑题与结构崩塌的概率。
2. **把评分标准写进提示词**：让模型知道“好”的标准是什么，而不是自由发挥。
3. **用约束清单代替形容词**：不只说“写得好”，而是规定结构、字数、素材、语言、禁忌。
4. **让模型内部自检**：要求动笔前按标准检查，但不输出思维链。
5. **风格锚点而非模板**：给一段高分范文的气韵作参照，明确“只学其法，不抄其句”。

## 二、提示工程策略对照表

| 策略 | 在本项目中的做法 | 解决的问题 |
| --- | --- | --- |
| 角色扮演 | 设定为“特级教师 + 高考阅卷组组长” | 锚定专业语域，减少口语化、网络化表达 |
| 标准对齐 | 写入基础等级 40 分（内容 20 + 表达 20）与发展等级 20 分 | 让生成目标与阅卷标准一致 |
| 任务分解 | 大纲接口与正文接口分离，正文依赖大纲 | 降低跑题、结构松散、分论点重复 |
| 结构化输出 | 大纲固定为“审题立意—中心论点—标题—结构—素材—提醒” | 输出稳定，便于前端展示与二次调用 |
| 显式约束 | 字数、段数、开头、结尾、辩证段、素材类型、禁用项 | 把“写得好”翻译成可检查的规则 |
| 少样本风格锚点 | 提供一段高分范文片段，注明“严禁照抄” | 学习气韵与论证方式，避免空泛 |
| 隐式自我检查 | 要求“动笔前在心里按评分标准自检” | 提升切题度与完成度，又不暴露思维链 |
| 反面约束 | 明确禁止套作、烂梗、空喊口号、材料罗列 | 规避常见低分特征 |
| 输出格式控制 | 只输出作文，不要解释、不要 Markdown 围栏 | 前端可直接展示、复制、下载 |
| 温度分层 | 大纲 0.7，正文 0.8，阅卷 0.3 | 兼顾创意与稳定，阅卷更客观 |

## 三、系统提示词（System Prompt）

```text
你是一位深耕高中语文教学与高考阅卷二十余年的特级教师，长期担任高考作文阅卷组组长，熟悉《普通高中语文课程标准》和新高考作文评分标准。

【评分标准内化】
- 基础等级（40 分）：内容（20 分）要求切题、中心突出、材料充实、思想健康；表达（20 分）要求结构严谨、语言流畅、文体规范。
- 发展等级（20 分）：深刻、丰富、有文采、有创意。鼓励透过现象看本质、揭示因果、观点具有启发性。

【写作铁律】
1. 审题第一：准确提炼题目或材料的核心矛盾与价值指向，立意不偏、不泛、不套作。
2. 结构清晰：议论文采用“引—议—联—结”或“总—分—总”，分论点之间有逻辑递进，不并列堆砌。
3. 材料鲜活：古今中外结合，事实准确，优先使用具体、有细节、少被滥用的素材；名言引用必须准确。
4. 语言有文采：长短句结合，适当运用排比、比喻、引用、对比，但拒绝辞藻堆砌和空喊口号。
5. 文体纯粹：议论文像议论文，记叙文像记叙文，不写成“四不像”。
6. 标题出彩：8—14 字，含蓄凝练，能统摄全文，避免“论××”“××的启示”这类平庸标题。
7. 严禁：套作宿构、网络烂梗、假大空口号、无逻辑的材料罗列、模板化开头。

【输出纪律】
- 只输出用户要求的内容，不解释写作思路，不输出 Markdown 代码块围栏。
- 作文正文使用自然分段，标题单独一行。
- 不要把内部自我检查过程写出来。
```

## 四、第一阶段：审题立纲提示词

输入变量：`title`（题目）、`material`（材料/要求）、`genre`（文体）、`word_count`（目标字数）、`style`（风格）、`extra`（附加要求）。

```text
【作文题目】
{title}

【题目材料 / 写作要求】
{material}

【文体】
{genre}。{genre_hint}

【目标字数】
约 {word_count} 字（允许上下浮动 10%）。

【风格目标】
{style}。{style_hint}

【附加要求】
{extra}

请先完成审题与构思，输出一份可以直接指导考场写作的详细大纲。严格按以下格式输出，不要写正文：

一、审题立意
- 材料关键词：
- 核心矛盾 / 价值指向：
- 我的立意：
- 容易跑偏的角度及规避：

二、中心论点
- 用一句 20—35 字的话概括：

三、标题备选
1. （8—14 字，含蓄有文采）
2. （8—14 字，观点鲜明）
3. （8—14 字，意象化）

四、结构提纲
- 开头（约 100 字）：如何引题、亮明论点
- 分论点一：
- 分论点二：
- 分论点三：
- 辩证 / 反方段：
- 结尾（约 100 字）：如何升华

五、素材与名言
- 事实论据 3 个（注明人物 / 事件 + 可切入的角度）
- 名言 2 句（注明出处，确保准确）

六、写作提醒
- 本文最需要避免的一个问题：
- 最容易出彩的一个地方：

注意：大纲要具体到可以直接落笔，不要空话。
```

## 五、第二阶段：依纲成文提示词

```text
{同上：题目、材料、文体、字数、风格、附加要求}

【已确认的写作大纲】
{outline}

【风格锚点（只学其法与气韵，严禁照抄句子）】
围棋中，弈者往往求胜心切，不知“以正合”的兵家正道，莫不想着“以奇胜”的诡道，希冀一招致胜，毕其功于一役。殊不知，妙手不可偶得，本手游刃有余，妙手才可练就。
庄子笔下的庖丁，其“以神遇而不以目视”的绝技背后，是十九年、“所解数千牛”的扎实基本功；达·芬奇惊世名画《蒙娜丽莎》的微笑，其神韵或许从画蛋练功中绘就；苏轼的意到笔随，常有神来之笔，其才情在“立志读尽人间书”的苦读中酝酿。
守拙以守正，苦练基本功，练就本手；创新兼创意，熟能生巧，才能妙手偶得。

请严格依据大纲，写一篇可以直接誊写到答题卡上的高考{genre}。要求：
1. 标题单独一行，不加“题目：”等字样。
2. 正文约 {word_count} 字，分段自然，议论文 5—7 段。
3. 开头 3 句内进入主题，结尾要有余味，不喊空洞口号。
4. 分论点句式有变化，材料与观点之间要有分析，不能“观点 + 例子”简单拼接。
5. 至少有一处辩证思考或对反面观点的回应，体现思维深度。
6. 动笔前在心里按评分标准自检：是否切题？结构是否清晰？材料是否准确？语言是否有文采？
7. 只输出作文本身，不要输出大纲、说明、字数统计或 Markdown 围栏。
```

快速模式（`mode=fast`）会跳过显式大纲，把“先审题、立意、结构、素材自检”放进同一次调用，适合快速试写；标准模式更适合追求稳定高分。

## 七、迭代记录

| 版本 | 做法 | 观察 | 调整 |
| --- | --- | --- | --- |
| v1 | 单次调用，直接要求“写满分作文” | 容易写成“观点 + 例子”的堆砌，结构不稳定 | 拆成“大纲 + 正文”两阶段 |
| v2 | 加入评分标准，但仍只写“内容/表达/发展” | 模型对“发展等级”理解空泛 | 把“深刻、丰富、有文采、有创意”展开为可执行约束 |
| v3 | 加入范文风格锚点 | 语言更有文采，但出现模仿痕迹 | 明确“只学其法，严禁照抄句子” |
| v4 | 加入“动笔前自检”和禁用项 | 切题度、完成度提升，空话减少 | 保留隐式自检，不输出思维链 |
| v5 | 校正评分结构为 40 + 20 | 阅卷分项与总分一致，避免 70 分制误算 | 大纲 0.7 / 正文 0.8 / 阅卷 0.3 分温控制 |

## 八、可复用的提示词经验

1. **把形容词换成规则**：  
   “写得好”不如“5—7 段、开头 3 句内入题、至少一处辩证思考”。
2. **让每一步只有一个目标**：  
   大纲只负责“想清楚”，正文只负责“写出来”，阅卷只负责“挑问题”。
3. **给模型一个“反例清单”**：  
   明确禁止套作、烂梗、空喊口号，比只给正面要求更有效。
4. **用格式约束降低不确定性**：  
   固定大纲字段、固定阅卷结构，前端才能稳定解析和展示。
5. **温度不是越高越好**：  
   创意任务可用 0.8，评价任务应降到 0.3，减少“一味夸赞”。
6. **不要把思维链当成果**：  
   要求模型“内部自检”，但不输出过程，既提升质量，又保持输出干净。
